# 引用扩展怎样帮助实际研究

本轮沿用两个原研究问题：实验室 RAG 检索策略的可诊断评价，以及单细胞扰动预测的可信外推评价。先完成保存的引用分页，对所有图候选做相关性筛选，将推荐项纳入原集合并尝试全文获取，再让科研 agent 读取原件更新方案，独立复核其科学表述。

## 资料准备

单细胞六条引用流全部完成，无来源错误：从上一轮累计 8 次 HTTP 继续，追加 24 次，累计 32 次；返回 321 条去重图候选，其中相对主题广检索和种子集合新增 293 条。完成的是 OpenAlex 一跳索引，不是整个方向的文献检索。RAG 图返回 39 条，其中 34 条相对广检索和种子集合新增。

RAG 39 条逐条初筛：推荐 13、背景 9、待核实 12、排除 5；其中推荐的 11 条是引用新增，另 2 条曾在广检索出现。单细胞 321 条逐条初筛：推荐 98、背景 110、待核实 20、排除 93；扣除原已纳入 1 条后，97 条加入原集合。97 条含 79 条引用新增及 18 条广检索已见但未纳入项。筛选依据是标题、实际摘要、任务用途和方法边界；缺摘要保持待核实，引用连接不作为质量证明。

单细胞采用 21 个有效 DeepSeek 批次并经宿主复核、调整 18 项边界判断。实际发生 33 次模型请求，12 个无效身份/JSON响应被拒绝重试；改用受控短编号映射回稳定 ID 后完成。不将有效批次数冒充实际调用成本，也不据此报告人工节时。

各集合当前书目记录、明确关系去重的工作组、可读全文和严格目标状态，以[公开汇总](../examples/validated-cases/summary.json)为准。全文可读不代表目标版本已确认，二者分别统计。相似标题只列待核实，不自动并库。

原单细胞固定五篇中，Systematic Comparison 的正式版经公开路线取得，官方 bioRxiv API 确认其发表关系，组件复用原件满足原目标；可读工作由 2/5 增至 3/5。这是同一工作的可读正式版，不是新增独立研究。自动关联先于后续人工复核，原两版 ID 均保留。

其余失败保留获取任务：公开接口失败进入宿主浏览器；浏览器已实测 MDPI、机构仓储及 IEEE 页面。需要机构登录、人机验证、版本确认或宿主交回的项不算成功，也未逐一声称检查了所有等待项的浏览器页面。

## 实际阅读和方案变化

两个方案均真实调用已配置的 `deepseek-flash`，以项目局部规则进入原集合。RAG 最终运行 14 次工具调用、8 次原件读取，取得 5 篇新增主文的文字；单细胞 17 次工具调用、11 次原件读取，取得 5 篇工作的片段，其中 4 篇是新增独立工作。未调用训练代码或预测基准。

| 用例 | 原方案已有内容 | 新材料支持的具体变化 |
| --- | --- | --- |
| RAG | 固定检索器对照、claim/覆盖指标、成本及人工检查 | QA 生成与人工改写分轨、词面重合控制；新增配额 hybrid 的独立对照；可选共形 claim 过滤后处理，隔离开发/校准/测试并审计校准标签与分布假设 |
| 单细胞 | 未见扰动/背景划分、简单基线、PearsonΔ 与分布指标 | 为共享 control 噪声增加独立 control-split 和样本量敏感性；用技术/真实重复作为评价阳性对照而非预测器；明确 scaffold/cell 联合留出和排除组；记录 DE 指标的适用条件和预印本复现缺口 |

这些改变分别给出了实验分轨、数据隔离、对照、指标适用条件或失败判据，能够避免将摘要主张直接搬进方案。旧方案已有的成本、基线和人工复核被保留，不冒充全部由新论文首次发现。

## 复核发现的真实问题

首轮 RAG 模型在换页时沿用上一组选页的字符偏移，跳过正文后误称页面不可读。组件因此新增可直接重放的 `continuation` 和 `offset_scope`，工具说明要求换页偏移归零；再以逐页读取、只提供中性导航重跑。最终 RAG 已正确续读共形方法关键页，原始错误稿保留用于诊断。

工具修复仍不能保证模型遵守全部阅读要求。单细胞运行有 4 次截断且未续读，原回答却过度声明完整阅读；独立复核修正了这个声明。两份原始回答还存在校准与调参混用、相关性或零偏差的过强推论、把评价对照当作部署方法、把未复现预印本当作确定结论等问题。复核稿明确标记补读，未将复核者额外读的页面冒充模型亲读。

因此，本轮证明的是新增文献能够带来**可定位的设计纠错与更明确的适用条件**，并证明原件、工具、项目规则和复核链路可衔接。它没有证明未经复核的模型方案可直接执行，没有训练性能结果、统计显著的方案质量比较或人工节时比例。
