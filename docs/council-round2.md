# 第二轮多 Agent 议会评审

日期：2026 年 11 月 2 日。先完成种子恢复、引用扩展和全文备用路线开发及两个真实用例复跑，再由三席交叉审查。每席先只读复现和提出问题，采纳后集中修复，最后由提出问题的一席或主实现者复核。

## 三席分工

| 席位 | 审查范围 |
| --- | --- |
| 种子与引用数据席 | 来源真实命中、版本身份、图方向与分页、失败分类、覆盖和新鲜度 |
| 全文稳定性与版本席 | 公开路线回退、严格版本目标、PMC 版本窗口、浏览器交接和人工障碍 |
| 研究工作流与验证席 | 模型/MCP 实际可用性、对照成本口径、原件路径和材料包、科研收益表述 |

## 已采纳问题

| 发现 | 级别 | 修复和验证 |
| --- | --- | --- |
| 同一聚合来源从明确 arXiv v1 更新为 v2 时覆盖旧版本 | P1 | 从仓储标识、DOI、来源记录中选版本身份兼容者，否则创建新版本。覆盖有无共享 DOI、重复更新、旧版本回看及原材料归属；复评追加正式版共享 arXiv 别名的重复导入测试，防止无限新增版本 |
| PDF 首页 v2 或 v10 被当作明确请求的 v1 | P1 | 提取完整 arXiv 标识，按工作和修订比较，禁止子串推断；不同版本保留待确认，不能满足严格目标 |
| 已下载正确 arXiv PDF，但解析位置缺少身份导致严格任务不满足 | P2 | arXiv 路线传递真实标识；OpenAlex/Unpaywall 仅在响应 DOI 核验一致后传递精确身份，不补造缺失标识 |
| 模型和 MCP 可执行任务却无法恢复暂停的检索与图任务 | P1 | 新增 resume_job、cancel_job；模型恢复仅允许 discovery/frontier/citations，获取仍走公开重试或宿主浏览器恢复。实际 Core 续页与真实 MCP 均验证 |
| PubMed 200 EFetch 少返记录仍推进游标并刷新覆盖 | P2 | 校验请求与返回 PMID 集合、重复和意外项；不完整返回可重试错误并保留原页，不写完整 search_runs |
| 引用图来源故障最终被写成不可重试的种子不存在 | P2 | 未核实时保留来源错误、重试属性及尝试信息；仅有效负响应才 SEED_NOT_FOUND |
| 单细胞广检索实际 9 次 HTTP 被写成预算合计 8 次 | P2 | 报告新增每个 broad job 的预算、实际请求和超出数；从持久任务补录实际成本，未改变种子结果 |
| PMC 有多个仓储版本时只扫描最旧三版 | P2 | 无明确目标版时最新优先，显式版本仍精确选择；保留三版有界扫描和窗口限制提示 |

实现方同时补上旧失败获取任务与另一个活跃替代目标冲突时的显式跳过，避免重试触发数据库唯一键异常。浏览器交回保留公开路线诊断，不要求研究者维护逐篇证据卡。

## 真实结果和使用边界

结果详见[第二轮优化与验证](optimization-round2.md)。集成种子恢复为 RAG 2/2、单细胞 3/3；图扩展相对本轮集合新增 34、83 条候选，未经逐篇相关性筛选。固定纳入集合全文仍为 5/5、2/5，三个缺失项明确需要机构登录或人工验证。

验证席实际核对两份 bundle：RAG 5 个 PDF 与 1 个代码说明，单细胞 2 个 PDF 与 2 个代码说明，全部相对路径、原件/提取路径及 SHA256 通过。独立空库的 RAGChecker 27 页 PDF 证明备用路线可成功，不当作原集合新增收益。

三席均已解除所报阻塞：数据席独立复现确认 v1/v2 不覆盖、重导不重复、回看不降版；全文席的严格版本、精确解析身份及 PMC 窗口修复通过专项回归；工作流席确认任务续接和真实成本口径已修正。

最终全套为 **310 passed、1 skipped**；被跳过的真实 MCP 检查已另外显式运行，**1 passed**，覆盖新增工具列出和实际调用。版本修复后再次在独立空库通过真实备用路线下载 RAGChecker，仍为 27 页、2,553,412 字节、2408.08067v2。两个 bundle 共 10 个原件的哈希和路径通过；16 份文档的本地链接、代码围栏，以及源码/文档/示例的凭据隔离检查通过。结论为可继续按单机内测边界使用。

仍按实验室单机内测边界使用：广检索有预算暂停；引用是 OpenAlex 的工作级索引，空参考列表不能证明论文没有参考文献；单细胞图尚未遍历完。组件没有完成全领域检索、自动越过登录验证、重新生成科研方案或执行实验。

## 下一步优先顺序

1. 研究者或宿主解决三个实际访问障碍，再恢复对应浏览器任务；成功原件继续复用。
2. 用已补齐的模型/MCP 续接接口继续单细胞图，筛选新增候选，再纳入既有研究集合和获取全文。
3. 用研究者整理的相关文献集合建立可比召回和相关性基准；当前不报告人工节时百分比。
4. 在实际集合规模需要时补材料列表分页，随后考虑更正撤稿同步和备份恢复。

本轮议会已执行，不代表设置了周期自动化、后台常驻评审或自动通知。
