## 阅读与核验机制

[关键细节接口](checked-reading.md)把实际读取、解释复核和最终稿接收分开。少量任务问题由宿主设定，模型通过实际原文片段地址提交解释；版本、角色、集合归属或真实文件字节变化使旧锚点失效。跨页定义有相邻页接口，截断范围须续读，审阅者得到实际已返回的上下文。解释修改后旧审核失效；最终稿另经独立调用，回执绑定实际文本哈希。

本轮也证实复核会失误：纯自主运行多次被范围、上下文或预算约束拦下；后来同模型复核还漏过了 FP/FN 反转及跨用例内容混入。原始输出没有覆盖。公开稿采用 Codex 对来源、指标、校准预算与风险层级的校正，再对具体最终文本独立复核。通用数学参考单独标注，不能拿来证明论文的实际标签。

## 两个真实用例

最终工作流为：宿主按已选范围一次读取，科研 agent 根据真实返回内容和片段地址提出方案及关键解释，独立调用复核，针对未通过项修订；Codex 进行额外来源/指标审阅后，再复核校正后的最终稿。它是与 agent 自主调用工具并存的宿主接入方式，没有用固定答案替代实际模型阅读。原文传输范围已获得用户明确授权。

RAG 使用 FRESCO 3–5、EBG 3–4、RARE 6–7。方案实质变化包括时效指标的条件分母、Fail 正类下误删/漏拦的方向、逐实例合取与汇总联合率的区别，以及证据干预和冗余等价 gold。见[最终 RAG 方案](../examples/checked-reading/rag-plan.md)。

单细胞使用 PIE 4/6/8、DE 分类 10/11、SafeDelta 6 及固定提交的 adapter.py。方案明确零样本与使用校准响应的 few-shot 信息预算，区分全量/curated 与三类/二类指标，并把平均收益、有害释放风险、独立控制假设和实际 split 审计分开。见[最终单细胞方案](../examples/checked-reading/bio-plan.md)。

实际读取次数、字符、通过项、最终文本哈希及所有保留运行的状态见[验证摘要](../examples/checked-reading/summary.json)。模型首次实读和末稿再次核对分别标注，不重复计成新的独立科学研究。旧错误控制即使读到原文，也没有得到最终接收；对应 verdict 可能是 contradicted 或 needs_context，均保留原值。

两个实际研究项目均通过受管写入升级至 AGENTS.md v3，并核对真实规则入口已加载。原规则区块外的研究者内容保留；不能只以规则文件存在代替宿主严格检查。

## 验证边界

本地完整离线回归、真实 MCP stdio 和公开文件清单检查完成后同步公开仓库；具体提交的自动检查由公开 CI 验证。边界、回归依据和剩余风险见[复审记录](../examples/checked-reading/council.json)。密钥、原始论文、作者代码副本、完整摘要、浏览器载荷及私人路径均不公开。

本轮支持“原件获取、模型实读、关键定义纠错与方案约束实际发生”的结论。没有训练、科研基准执行、完整复现或节时对照实验，不能据此宣称科学性能提升；任何 supported 状态也不保证后续研究判断正确。
