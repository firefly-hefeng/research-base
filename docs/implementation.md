# 当前实现和设计差异

日期：2026 年 11 月 2 日。程序版本：0.1.0。本文件说明目前可运行的内容；原设计文档保留作为基线，未交付的部分不因出现在设计中而视作已实现。

## 已实现的使用闭环

Python 内核、CLI、stdio MCP 和可选 DeepSeek agent 共用本地库。研究者能够创建集合、多源发现、筛选和纳入论文、获取公开 PDF、交接浏览器任务、读取原件或分页文本，并把 collection 接入研究项目。

当前八个来源为 OpenAlex、Crossref、arXiv、Europe PMC、PubMed、Semantic Scholar、DOAJ 和 DataCite 的文献出版物检索。来源覆盖和语法限制见[来源说明](sources.md)，后两项的真实验证与开源获取工具取舍见[来源评审记录](council-sources.md)。DataCite 的数据集和软件不作为论文计数；不同来源间存在大量重叠。

第二轮新增 discover_frontier 的来源核实种子恢复、独立一跳引用扩展 expand_citations 和公开获取重试 retry_acquisition。广检索命中快照、种子恢复和引用候选分别记录，不用已有库记录冒充新召回，不用引用扩展刷新主题覆盖时间。OpenAlex 无密钥改用官方普通分页，明确保留结果窗口上限。接口及实际对照见[第二轮优化记录](optimization-round2.md)。

获取优先使用搜索返回的公开全文位置。缺少位置时使用已知 arXiv、PMC 和 DOI 的公开解析路径；DOI 可通过 OpenAlex 补查 OA 位置，有明确 UNPAYWALL_EMAIL 配置时还可查询 Unpaywall。来源暂时故障与缺少全文分开记录，未满足目标进入浏览器或人工确认。

开放获取仍可能失败，机构内网浏览器是可接入的后端。首版提供领取、续租、文件交回、验证和恢复协议，由现有宿主执行 computer-use；没有在服务中捆绑浏览器驱动。实际测试已通过现有浏览器下载公开论文，再从默认下载目录复制到独占暂存目录交回。

## 原件与整理

- get_paper 和 list_materials 同时提供论文版本、材料用途、获取状态与 local_path、text_path、pages_path。同机科研 agent 可用自身文件、PDF 或代码工具直接读取；read_material 提供按页和字符偏移读取。
- bundle 导出复制已获取的原件，生成相对 bundle_path 与清单；远端不能直接使用本机绝对路径。导出要求新目录或空目录，避免混入此前集合文件。
- 书目迁入支持 BibTeX、RIS、CSL JSON 和 Zotero API JSON。导出中指定的本地附件不会自动读取；研究者可通过材料导入入口明确关联。
- 一篇文献可属于多个集合，原件按哈希存储。标签目前是全局书目标签；项目自己的纳入状态由 membership 单独保存，集合专属用途标签在后续实现。
- 来源更新不会重置纳入或排除决定。书目导入默认产生 candidate；模型的 select_papers 只提出已有候选 ID 的建议，纳入仍是显式操作。

## 研究工作流

prepare_context 基于当前任务检索集合，并保留原件入口和缺口。它不会在读取操作中隐式启动网络检索或生成持久知识卡。上下文的新鲜度与实际检索计划关联；预算暂停和来源失败不会刷新完整检索时间。

Collection 可保存检索、获取版本策略和上下文默认值，显式请求参数优先。项目配置中的 context、freshness 和 discovery 用于上下文选择及范围判断。CLI 的网络发现仍以显式选定的库、集合和参数执行；项目文件不会自动回写共享集合。

如果没有配置检索计划，只有唯一已观察计划时可作为范围依据；出现多个不同计划则报告范围未确定，不能把最新一次局部查询时间当作整个方向的更新。固定历史截止时间也不代表已覆盖今天的研究。

AGENTS.md 接入有 manual 和 agents 两种方式。组件只管理标记区块，保留原有规则，支持冲突检测和中断恢复。规则是否被宿主加载必须实际验证；MCP 工具存在不代表宿主具有浏览器、文件读取或自动规则注入能力。

## 与原设计的差异

| 部分 | 当前实现 |
| --- | --- |
| 库映射 | 使用显式 --library 或 RESEARCH_BASE_LIBRARY；library_ref 是项目逻辑记录，尚无用户全局库名称注册表 |
| Worker | 显式运行单机 worker；以库锁串行执行，同机浏览器工作者通过租约协调；不是常驻调度服务 |
| 请求预算 | 按来源页边界暂停；一个 PubMed 页或重试可包含多个 HTTP 请求，报告实际次数及 budget_overshoot，非逐请求硬配额 |
| 下载续接 | 已完成目标和来源游标可续接；中断中的单个 PDF 会重新下载，尚无 HTTP 字节范围续传 |
| 文本处理 | 分页提取及中文子串回退；复杂表格、公式、扫描件交给原件/宿主，无 OCR 或语义检索插件 |
| 原始代码和数据 | 可登记链接及手动导入文件；真实用例可关联作者 README 快照，尚无通用仓库镜像或大数据下载器 |
| 获取身份 | 自动检查标题和身份区标识；不确定时保留文件并请求确认。版本类型和正文角色的复杂情况仍需人工判断 |
| 生命周期 | 任务和规则恢复已测试；JSONL、BibTeX、bundle 可导出，尚无完整备份恢复 CLI 或更正撤稿同步 |
| 多用户部署 | 当前只支持同机库访问，不把可写 SQLite 放共享网盘供多机器并发写入 |

## 验证与下一步

基础真实检查已经覆盖公开来源、PDF 下载和文本提取、DeepSeek 工具调用、实际 MCP 连接、浏览器文件交接。研究流用例和实际执行结果见[科研用例](use-cases.md)；操作入口见[快速开始](quickstart.md)。

第三轮真实研究流补上阅读续接契约后，当前回归为 312 项通过、1 项真实 MCP 检查在常规测试中跳过；该 MCP 检查另行显式验证。工具列出、结构化种子任务创建、状态读取、恢复和取消，以及来源响应错误、种子身份、引用分页、备用获取、版本关系、路径和规则接入均包含回归。原第二轮 310 项结果保留在议会历史记录。第三轮资料和研究方案验证见[研究工作流记录](research-validation-round3.md)。

开发完成后通过多 agent 议会审查来源覆盖、获取可靠性、原件整理和科研流程。评审应以失败用例和实际使用成本确定下一轮任务，不能用更多来源名称或下载数量替代研究效率。未经人工基准比较，运行时长和工具调用数只作为操作记录，不宣称已经证明效率提升百分比。
