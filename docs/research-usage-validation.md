# 研究知识注入升级验证（2026-11-03）

本轮把“局部规则要求参考文献”升级为“关键原件入口、按研究任务导航、宿主观察实际读取、输出前检查”。论文及其代码和附件继续作为知识主体，不建立额外的逐篇知识卡。

## 已交付

- `configure_frontier/get_frontier`：为集合配置少量关键论文及默认学科，保留版本、原始路径、获取缺口和真实检索日期。
- `prepare_research/begin_research`：按探索、设计、实现、解释和创新性阶段，以及通用、机器学习或单细胞学科提供阅读入口和需要核对的问题。
- `extend_research/read_research_material/check_research/end_research`：支持任务过程中自主扩展论文、读取原文、处理续读、检查实际使用和释放会话。
- AGENTS.md v2：绑定项目的实际入口加载、受管区块安全升级、宿主建立任务会话，以及关键结论前的使用检查。
- 内置 agent：默认约束所有绑定集合的研究任务；未读或未完成选择范围时不发布模型的科学草稿。创新性阶段还要求对应检索计划的新鲜度满足。无集合绑定的管理任务保留原来的工具流程。

完整调用和宿主接入方式见[研究知识接口](research-knowledge-interface.md)。同机原始路径仍可自由访问；要进入程序检查，需由可信宿主读取器登记实际返回内容，或使用可观察的读取工具。

## 两个真实资料集

验证复用此前的 RAG 评价和单细胞扰动预测集合，不重造合成论文。每个方向设置五篇关键入口，并为这次任务明确选择两篇需要核对的原件。只完成本次所选物理页范围，不冒充全文通读。

| 检查 | RAG | 单细胞 |
| --- | --- | --- |
| 只有导航、元数据 | 被拦截 | 被拦截 |
| 只有原件路径 | 被拦截 | 被拦截 |
| 所选范围截断且未续读完成 | 被拦截 | 被拦截 |
| 必要范围完成后 | 可合成，保留检索限制 | 可合成，保留检索限制 |
| 宿主验证读取调用 | 10 | 13 |
| DeepSeek 科研 agent 本轮验证 | 3 次实际读取、14,359 个返回字符 | 4 次实际读取、16,104 个返回字符 |

单细胞 agent 实际取得校准指标论文物理第 3 页，以及共享控制相关偏差论文物理第 2–3 页；第一篇经过续读完成。实际调用 `check_research`，宿主也在输出时重新检查。结果为 `completed_with_limits`：集合没有匹配当前范围的完整检索记录，不能据此宣称核对了当前全领域前沿。更改入口配置和读取原件不会刷新检索时间。

RAG 在线验证在用户明确允许传输必要片段后完成。科研 agent 实际读取条件共形事实性论文物理第 2 页，以及德语混合检索论文物理第 4、5 页，三个范围均完整返回；实际调用了 `check_research`，输出时宿主再次检查。结果同样为 `completed_with_limits`，未把原件可读或本次读取冒充前沿检索完成。

这次 RAG 在线运行额外限定两份原件和许可物理页：导航、搜索和论文详情只返回所选论文的元数据，正文仅通过显式页码读取返回。范围适配器不改变共享文献集合。六项本地范围测试和独立范围审查通过。两个用例的原件、模型原始输出与本机路径均保留在忽略目录，公开材料只提供必要结果和独立复核。

## 对研究工作的帮助及实际边界

单细胞输出确实从原文取得了指标校准、组合覆盖范围和共享控制质心偏差等设计信息，并明确区分所读页、未读公式、尚未完成检索及没有运行实验。对实际研究有用的修改包括：分别报告互补指标、避免仅凭稀疏组合任务判断非加性能力、增加独立控制拆分及不确定性诊断。

独立复核仍发现科学解释错误：模型把评价专用对照与预测基线混写，把有限条件下的排名性质说得过强，并对非零 null 估计过早归因。已在[独立复核方案](../examples/research-usage/single-cell-reviewed-design.md)中修正，[复核记录](../examples/research-usage/single-cell-review.json)保留具体修改范围。学科提示进一步要求区分需要 held-out 响应的评价对照、可部署预测器，以及指标噪声假设。

RAG 输出从原文识别了“问题级命中率”和 chunk 精确率的差别，也提出核查校准标注误差和独立评估。独立复核仍发现它把另一篇论文的页码误称为共形论文的额外读取、把“两块”写成“两语句”，并将查询隔离扩展为原文没有要求的检索语料块完全隔离。修订见 [RAG 独立方案](../examples/research-usage/rag-reviewed-design.md)和[复核记录](../examples/research-usage/rag-review.json)。复核额外读取的页面与模型真实读取范围分别记录，不冒充模型已读。

因此，本轮证明了接口实际被使用、漏读及续读缺口可被拦截、原文能改变设计；没有证明模型可以无人复核地产出正确研究结论，也没有测量实验性能或节省时间的百分比。

## 多 agent 议会

三个独立分工分别检查前沿空间、运行约束及规则接入，并交叉复核真实单细胞材料。发现并修复：

1. 预算耗尽后的整理须保留新原文读取接口返回的文本。
2. 动态扩展不得清除宿主指定必读材料或既有读取记录。
3. 输出检查须使用实时检索状态；创新性不能仅凭缓存原件通过。
4. 显式声明使用但未读的论文不能被后续空参数检查遗忘。
5. 已验证关联版本的实际材料所属论文可正确引用；材料改为非原始资料后旧记录失效。
6. 长期连接支持会话清理；模型不能关闭或替换宿主绑定会话以绕过检查。

最终复核未发现剩余的阻塞性程序问题。本机 Windows/Python 3.11 前轮全量离线测试 362 项通过，真实 MCP stdio 协议测试另有 1 项通过；RAG 获授权后新增的 6 项材料范围测试也已通过。测试覆盖实际本地材料、续读跳偏移、身份及成员变化、未读结论拦截、安全规则迁移、项目范围覆盖、可信视觉回调和在线验证的片段传输范围。111 个待公开文件的敏感内容与链接检查无问题；这项检查不包含本地原件或密钥，也不表示本轮改动已发布到远端仓库。
