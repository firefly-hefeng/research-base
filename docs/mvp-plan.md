# 首版最小可用版本开发计划

首版的交付目标是让研究者能把一个方向的论文收集为可使用的材料集合，并让实际研究 agent 在关键任务前查询和读取它。开发采用单机部署、开放接口优先、同机浏览器接续。T01 至 T10 的基础使用闭环已实现并进入真实用例验证；范围差异及未交付部分见[实现状态](implementation.md)，不能将下列原始验收清单全部视作已完成。

模块和数据边界以[总体设计](design.md)为准；接口与状态以[接口契约](interfaces.md)为准；项目规则写入以[接入机制](agent-integration.md)为准。示例载荷在实现请求响应类型时纳入契约检查。

## 首版完成标准

一次端到端演示应完成：建立库和集合 → 用两个开放来源检索 → 去重并显式纳入 → 批量获取主文 → 至少一篇通过真实宿主浏览器接续 → 检索全文并按页读取 → 接入一个已有 AGENTS.md 的研究项目 → agent 基于当前任务找到并读取相关原件。

演示集合可选择 20 至 50 篇已确认相关的论文，至少包含重复记录、无全文项、正式版与预印本关联、扫描或解析异常、浏览器障碍及重试情形。数量用于检查批量行为，不作为全文获取上限或覆盖率承诺。常规测试中的异常用本地样本稳定复现，真实数据库是否出现验证码等情况不作为发布必需条件。

首版不要求语义检索、自动综述、专属浏览器驱动、专业数据库连接器、自动代码执行、图形界面或实验室多用户服务器。

## 阶段和依赖

| 阶段 | 任务 | 可演示结果 |
| --- | --- | --- |
| A 数据与材料 | T01 至 T03 | 已有论文能导入、归一、检索和读取 |
| B 发现与获取 | T04 至 T07 | 外部文献能进入库，开放全文和浏览器路径均可续接 |
| C 工作流接入 | T08 至 T10 | agent 能查询集合，项目规则可安装和卸载 |
| D 试点发布 | T11 至 T12 | 有真实宿主演示、导出备份和可重复安装说明 |

关键依赖：T01 → T02 → T03；T02 → T04 → T05 → T06 → T07；T03 与 T05 → T08；T08 → T09；T07 与 T08 → T10；T07、T09、T10 → T11 → T12。T09 的规则文件处理可在 T02 后独立开发，最后与 T08 联调。

## 开发任务

### T01 建立内核工程和领域契约

交付：Python 包、CLI 入口、配置读取、统一结果和错误类型、核心实体及请求响应模型。采用 src 布局；依赖版本在实施时锁定。内核不引用特定模型 SDK 或浏览器实现。

建议目录：

```text
src/research_base/
  domain/             # 身份、集合、材料与任务类型
  services/           # 发现、获取、读取、上下文和接入用例
  storage/            # SQLite、原件、迁移和锁
  adapters/sources/   # OpenAlex、Crossref
  adapters/fulltext/  # 公开全文解析和 HTTP 下载
  adapters/browser/   # 领取与交回协议，不内置浏览器
  adapters/parsers/   # PDF 分页文本
  entrypoints/        # CLI、MCP
```

验收：配置和 examples 中的 JSON 可通过对应模型读取；非法 schema_version、路径和 ID 返回明确错误；CLI --json 结果与领域对象一致。源码目录不在本轮设计工作中提前创建空壳。

### T02 实现存储 身份归一和集合管理

依赖 T01。交付：数据库迁移、库初始化、逻辑名称映射、Paper/Version/Material 与集合管理、标识符约束、纳入和排除操作。

验收：同 DOI 的来源记录不会重复建版本；不同版本仍可独立读取；标题相近但无法确认的论文不误合并；库身份不匹配时停止；重复执行纳入无重复成员。候选、纳入和排除状态可明确查询。

### T03 实现材料导入 分页提取和本地检索

依赖 T02。交付：原件按 SHA256 入库、PDF 分页文本、FTS5、CJK 子串回退、search_library、read_material、材料 URL 登记。补充材料可手动导入，代码和数据至少能登记外部入口。

验收：已知页的内容可检索并按同一 PDF 物理页码读取；摘要和全文命中范围可区分；中文子串有明确回退；重复文件不重复存储；扫描或坏文件状态可见；提取失败不删除原件。读取长材料会报告截断和继续读取方式。

### T04 实现持久任务和基础 Worker

依赖 T02。交付：Job/Task/JobTask、基础生命周期、worker run、get_job、resume/cancel、检查点、目标幂等、引用计数和事务基础。先以本地可控任务验收，再承载真实发现与获取。

验收：进程中断后能继续；相同 request_id 和载荷重放得到同一 job；同一目标不会有两个活跃 task。多 job 可关联同一 task；取消只影响当前关联，最后引用取消才停止任务并撤销租约。已入库材料保留，取消的 job 不被后续成功改写。

### T05 实现开放来源发现

依赖 T02、T04。交付：OpenAlex 和 Crossref 适配器、统一候选记录、来源专属检索式、分页游标、请求预算、逐来源状态和更新检索。研究者或宿主提供同义词和查询计划，首版不内置 LLM 查询规划。

验收：跨源重复项归一；限流和来源失败保留其他结果；预算暂停能从检查点继续；只有当前计划的完整检索才刷新对应完成时间，改变来源或查询后不误报新鲜；不会自动纳入全部候选。用保存的真实响应做常规测试，以小规模联网检查确认当前 API 可用。

### T06 实现开放全文下载和获取编排

依赖 T03、T04、T05。交付：OpenAlex 内容入口、来源公开 PDF、已知 arXiv 标识的 PDF 位置解析；流式下载、超时、限流、有限重试和统一校验入库。获取编排应用现有任务骨架，开放通道用尽后创建浏览器等待项；补齐人工确认及已入库文件重新匹配目标。

验收：有效 PDF 可入库；HTML 错误页、未完成下载和标识冲突不自动成功；身份或主文角色不明可确认；版本满足策略后才完成目标；单篇失败不阻塞其他下载；大文件流式处理。中断和重复请求不重复下载成功对象，人工导入能解除匹配等待项。partial 只用于已经结束的部分成功 job，等待浏览器或用户时状态准确。

### T07 实现浏览器领取与文件交回

依赖 T06。交付：claim、renew、submit、resume 四个操作及 CLI 包装、租约独占目录、结果幂等、交回校验和人工导入接续。一份宿主操作说明应能驱动真实 computer-use 完成任务，不要求首版内置自动浏览器循环。

验收：两个工作者不能同时持有有效租约；旧租约不能覆盖新结果；重复提交返回同一响应；accepted 之前文件已归核心持久保管；验证期间租约到期不重复下载。边界外路径被拒绝，补充材料不能完成主文任务；登录障碍可恢复；not_found 有明确终态。至少一次真实宿主完成完整交接，无工作者时清楚报告 waiting_external。

### T08 实现任务上下文入口

依赖 T03、T05。交付：prepare_context 和 CLI context，支持显式集合及项目配置；返回相关论文、全文状态、匹配片段、页码、更新提示和后续动作。

验收：返回受篇数和字符预算约束；截断可见；无相关材料时报告缺口；全文缺失不悄悄消失；candidate 可提示但 excluded 不注入；改变检索计划时报告 scope_changed；不隐式联网或生成证据卡。

### T09 实现项目绑定和 AGENTS.md 管理

依赖 T02，联调依赖 T08。交付：attach/detach/doctor、manual 与 agents 模式、固定模板版本、管理区块、dry-run、字节保留、冲突检测、锁及中断恢复。

验收：空项目安装成功，重复执行无变化；manual 不写入口；模式切换安全，重复 detach 不创建文件；项目默认值不回写共享集合。原有 Vesti、其他区块及 UTF-8 BOM/换行保留；用户修改区块、半截或重复标记返回冲突；换集合只改必要配置；卸载保留资料和原有规则；不误写祖先目录，链接越界与并发修改能检测。

### T10 包装最小 MCP 接口

依赖 T07、T08。交付：六个核心工具、set_membership、浏览器交接工具，以及 import_material 和 confirm_material_identity；本地 stdio 配置示例。库和项目管理仍可通过 CLI 完成。

验收：MCP 和 CLI 返回同一数据和错误语义；异步调用及时返回 job ID；worker 启动方式清楚，进程退出后任务可续接；stdout 只有协议消息。通过 SDK 的实际连接检查工具发现、调用及分页结果。不依赖宿主支持自定义资源 URI 才能完成读取。

### T11 完成真实宿主与实验室试点

依赖 T07、T09、T10。交付：一个实际研究方向的集合、一个宿主的 MCP/CLI 接入步骤、浏览器操作说明，以及一份简短 skill 使用说明草案。草案不自动安装到用户全局目录。

验收：宿主在一个研究问题或实验设计任务前主动取得上下文并读到相关原文；涉及实现时能找到代码入口；已有项目规则不受损；无全文、登录障碍和过期提示能被看见；不自动加载 AGENTS.md 的工作流可通过手动提示完成同一调用过程。

试点记录只需包含实际来源、检索时间、候选/纳入/全文数量、失败原因分布和使用反馈，不扩展为逐篇证据报告。真实网络演示取得哪些结果据实记录，不能以离线模拟冒充浏览器获取成功。

### T12 导出 备份和首版发布

依赖 T11。交付：JSONL/BibTeX 导出、本地备份恢复说明、Windows 安装和卸载步骤、已知限制、可重复演示流程。更新 README 为真实已实现状态。

验收：备份恢复后标识、集合和原件关系可读；索引可重建；移动库根后通过 library_ref 重新映射可读取资料；卸载程序不会删除研究原件。发布说明区分已实现与后续能力。

## 必要测试集合

| 场景 | 检查目标 |
| --- | --- |
| 多源重复与版本差异 | 去重不误合并，标识关联不丢失 |
| HTML 伪装 PDF、DOI 出现在参考文献、仅摘要页 | 文件格式与身份检查不凭文件名或任意 DOI 误判 |
| 扫描 PDF 和解析异常 | 获取成功与可检索状态分离 |
| 网络限流、中断与预算暂停 | 可续接、计数准确，不重复下载已成功对象 |
| 浏览器租约过期、迟到与重复交回 | 幂等、状态正确，旧工作者不能覆盖新结果 |
| 暂存目录越界、链接和文件替换 | 校验的内容与入库对象一致 |
| 多个 job 复用和取消 | 取消作用域明确，不破坏其他请求 |
| 现有规则、手工编辑和写入中断 | 字节保留、冲突可见、恢复不覆盖外部内容 |
| CLI 与 MCP | 同一业务契约，stdio 输出正确 |
| 实际宿主与浏览器 | 能将工具、文件系统和浏览器能力接到同一流程 |

常规测试以小型可控的合法样本为主。线上来源和浏览器检查单独标记、显式运行；不把实时搜索结果的精确排序和第三方站点的固定按钮坐标写成稳定断言。

## 开始开发时的顺序

先完成 T01 至 T03，使手头已有论文可以进入库并被 agent 使用。随后完成发现和自动获取，再接浏览器；这样每一阶段都能产生可验证的用途。MCP 和规则管理复用内核，最后在同一真实宿主中联调。

首个真实试点只需要确定一个研究方向和一个具有 computer-use 及本地文件交接能力的宿主。这两个选择不阻塞内核、协议、集合和规则管理的开发。时间估算应在 T03 完成后，依据真实 PDF、网络来源和宿主适配成本给出。
