# RAG 评价方案：独立复核版

本稿与原始模型输出分开保存。科研 agent 实际读取了《Response Quality Assessment for Retrieval-Augmented Generation via Conditional Conformal Factuality》物理第 2 页，以及《Hybrid Retrieval for Retrieval Augmented Generation in the German Language Production Domain》物理第 4、5 页，共 3 次调用、14,359 个返回字符。模型关于额外读取前一篇第 4、5 页的声明没有调用记录支持。独立复核另读了前一篇第 3 页和后一篇第 9 页；以下涉及条件校准和合成问题偏差的补充来自这部分复核，不能归为模型亲读。两篇都未通读，本轮未运行实验。

1. 冻结检索语料、分块规则、生成器、上下文预算和评价设置，再比较 BM25F、稠密检索及配额混合。按预先划定的开发集选择块长和混合比例，冻结后评估测试集；相近或重复问题应分组隔离。固定检索语料可以供不同集合使用，不能把“校准与测试查询独立”误写成禁止共享全部检索文档。
2. 将问题级命中率、chunk 级相关性、答案正确性和 claim 支持分开报告。混合检索论文所称 Precision 是命中问题数除以全部问题数，允许答案由一或两个 chunk 支持；它不是通常的 chunk precision，也不是“两语句容差”。采用同样协议时明确 top-k、跨块判定及 MRR 未命中记零的规则。
3. 把论文的 top-10 配额合并作为独立配置：从两检索器按 n=3/5/7 和剩余名额取结果、去重并补齐。它不等同于 RRF。对照组采用一致的语料、候选和上下文预算；另测索引成本及查询延迟，不直接沿用论文的跨系统提升数值。
4. 将 conformal 过滤作为独立后处理实验。校准需要真答案和 sub-claim 标签；冻结评分及标注流程，隔离开发、校准和最终测试，抽查自动标注误差。同时报告经验事实性、claim 保留率及答案完整性，不能把相似度评分本身当成事实真值。条件版本还需预先定义组、检查各组校准样本及推断时组标签可得性；相关保证有标签正确、分布等适用条件，不能直接外推到新域。
5. 结合独立复核的合成 QA 局限，加入人工改写或真实问题子集，并按语言和词面重合分层。德英问题不是配对集合，不能由总体差异推断纯语言效应。补查代码、附录、具体数据划分和结果后再固化实现；更新匹配的检索计划及其他关键工作后，才能讨论当前前沿或创新性。
