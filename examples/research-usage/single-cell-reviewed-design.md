# 单细胞扰动评估方案：独立复核版

本稿与原始模型输出分开保存。独立复核仅使用论文 A《Deep learning perturbation models can outperform baselines on calibrated metrics》物理第 3 页，以及论文 B《Spurious correlation inflates performance in single-cell perturbation prediction》物理第 2–3 页。科研 agent 经 4 次调用取得这三页的完整选定范围，共返回 16,104 个字符；不代表读完两篇论文。本轮未运行实验。

1. 分别建立未见扰动和未见组合任务，预先冻结训练、调参及测试集合。检查供体、批次、细胞类型与控制样本的关系。组合任务同时采用 Norman 类和覆盖更充分的数据，避免以单一数据集证明非加性预测能力；不能仅凭这些页确定具体拆分实现。
2. 在读取指标定义后，预先确定互补指标并分别报告。把 WMSE、weighted R²Δ、NIR 列为待核对的候选，同时保留 MSE 和相关性指标作诊断；这里的校准结果不保证每项指标在新数据中均可靠，也不意味着 MSE 普遍低估性能。按扰动强度、细胞数和测序深度做敏感性分析。
3. 比较 mean、control、PCA 线性及适用的 additive 基线。interpolated duplicate 使用 held-out 数据，仅作为评价校准或上界参照，必须与预测模型及调参流程隔离；PCA 线性不直接标作正对照。各基线应采用一致的可用训练信息。
4. 对共享控制质心的 Pearson Δ 估计，比较原始 shared 版本与独立控制组的 split 版本。重复随机拆分，报告均值、变异及控制和扰动样本数。加入控制均值预测的 null 参照；偏离零时检查采样波动、控制匹配、估计条件和预处理，不能直接认定泄漏。不要把该修正套用到定义不同的全部 Δ 指标。
5. 预先列出待验证假设：拆分后的排名是否稳定、指标对低质量数据是否稳健、非加性任务是否优于简单基线。补读指标公式、Methods、补充材料及代码后再固化实现；这些页不能确立跨供体或跨细胞类型泛化。检索新鲜度仍未确认，须更新检索并检查其他关键工作后才能作当前前沿或创新性判断。
