# RAG：时效、证据充分性与冗余条件下的分层评价方案

本方案基于实际返回的 FRESCO 物理页 3–5、EBG 页 3–4、RARE 页 6–7。以下实验均为拟执行方案，未运行基准、训练或代码复现；只覆盖本次选定方法页。

作者定义中，FRESCO 的 Obsolete Ratio 分母是排在正例之前的负例，分子是其中过时的负例，不能替换为“所有查询中 top-1 过时的频率”。RARE 过滤审计以 Fail 为正类：在“预测 Fail 则剔除”的过滤实现中，FP 是有效条目被剔除，FN 是无效条目被保留。EBG 使用 `lines` 数组和答案/证据联合评价；逐实例二值合取等于两指示变量相乘，但联合正确率一般不等于两个边际正确率相乘。

以固定候选池与信息预算比较：原始检索排序、无时间信息的重排、包含查询时点的重排及只按时间戳排序的简单控制。显式与隐式时效查询分别报告，避免将所有查询都视为追求最新答案。训练、调参与评估按实体及时间分组，检查模板与生成标签泄漏；执行前固定数据、模型与代码版本。

检索层分开报告必要信息覆盖比例与全部必要信息命中率，冗余等价证据按预先审计的等价组计分，不能只认唯一字符串或原始 chunk。重排层报告排序指标及 Obsolete Ratio；没有负例高于正例时，本项目预先规定记为不适用并单报占比，该约定不冒充作者已明确的零分母实现。另报 top-1 过时频率。

生成层分别计算答案、证据与联合正确率。联合率为逐实例“答案与证据均正确”指示值的均值；证据的全命中、部分命中和解析失败规则在人工核对后预注册，不将尚未读取的作者评估实现视为已复现。

瓶颈诊断对同一实例比较实际检索上下文与补齐必要证据的 oracle 上下文，控制长度、位置和格式；同时在固定证据条件下比较生成器。用配对改善与剩余错误量评估组件贡献，不能仅凭 oracle 条件仍有错误就断言主要瓶颈是什么。跨域相似度与冗余度的观察关联也不当作因果证明。

过滤抽查分别列 TP/FP/FN/TN、无效条目保留率与有效条目误删率；用 `metric_reference` 核对标签和动作的逻辑映射。统计以实体簇做配对重抽样，并对查询类型、语料域、上下文长度分层。区间不足以支持收益时保留不确定性，不宣称已有提升。

方法页带来的实质修订是：纠正时效指标分母、区分逐实例与汇总联合指标、纠正 Fail 正类下的过滤错误方向，并加入证据干预与冗余等价 gold。附录、完整评估代码和真实划分审计仍待完成。
