# 单细胞用例：新增材料对方案的实际帮助

本记录比较旧方案、保留的原始 DeepSeek 新稿与独立补读修订稿。没有执行预测实验，因此“帮助”指可核实的研究设计变化，不指模型性能或节时百分比。

| 旧方案状态 | 新原文带来的具体改变 | 判定 |
| --- | --- | --- |
| 以 PearsonΔ/Δ20 等指标检查扰动效应，未设置指标辨别能力检查 | Calibration 引入阴阳性参照与 DRF；修订稿把 duplicate 放在评价期，先检查指标灵敏度再解释模型失败 | 实质新增；原模型稿误把阳性参照当绝对天花板，已纠正 |
| 使用同一个对照均值的 delta 指标，没有估计器偏倚诊断 | Control splitting 说明共享随机参考带来的依赖；新增独立参考拆分、控制细胞数敏感性和 null 诊断，并保留衰减限制 | 实质新增；不能宣称拆分后普遍无偏或唯一正确 |
| U-ctx/U-both 只有背景和扰动留出的高层描述 | Leakage-aware 明确联合交集、单侧留出的排除记录、scaffold/MoA/连续相似度审计和大小匹配对照 | 实质细化为可执行协议；只在对应化学任务适用 |
| 训练集特征选择、DE 名单不回流训练已经存在 | 新预印本自述全队列选基因的转导式限制，修订稿明确拒绝照搬 | 主要是确认旧边界，不能算首次发现防泄漏原则 |
| 有均值和加性基线，但“扰动均值”实现未细分权重与任务可用信息 | Calibration 区分扰动等权；Comparison 给出背景迁移均值公式；修订稿区别细胞等权、扰动等权、目标对照+训练背景效应 | 实质澄清，避免不同信息量的基线混名比较 |
| 0/2、1/2、2/2 与加性基线已出现 | 新材料把 Seen0/1/2 与具体基准对应，并提示 Norman19 组合覆盖的限制 | 多为确认/补强，不能把整个组合划分概念算作新增 |
| 旧 Systematic Comparison 仅有预印本记录，无可读全文 | 正式 Science Advances PDF 可读并自动关联原工作；补读方法与指标定义 | 文献获取与可用性收益；不是新独立研究。人工关系核验发生在自动关联之后 |
| 未明确重复性 ceiling、残差端点与独立不确定性单位 | LOCO 给出一个条件化范例，同时自述 driver 重构未重跑和折检验反保守；修订稿只把方法作为待复现候选 | 有价值的设计假设与质量门；不是已验证的数值证据 |

## 真实模型阅读与额外复核

真实 DeepSeek 运行完成 17 次工具调用，其中 11 次是 `read_material`，返回 5 篇工作的原文片段；其中 4 篇是相对原集合新增的独立工作。共返回 44,997 字符，4 次调用只返回该页前 6,000 字符，未续读。`read-scope-audit.json` 保留逐次核对结果。

原模型写出了“完整读取五篇、每页均未截断”的错误声明，并将部分资料外推为强制主指标、绝对天花板或确定的泄漏判据。独立复核补读 Calibration p.5–7、LOCO p.9、Comparison p.16 等范围后，另存 `reviewed-plan.md`；这些阅读不算入模型日志，修订稿不冒充原始模型回答。

## 未证实与下一步

尚未证明：预测准确率提升、某方法优于另一方法、完整前沿覆盖、人工节时或成本改善比例。没有直接读到原 simple-linear-baselines 论文全文时，不能声称完成了双方主张的完整复现；目前已直接阅读 Calibration 对此前结果的讨论。

可继续的科学验收是：按修订清单在小数据集实现相同输入契约和训练折特征选择，运行阴阳性指标诊断、shared/split control 对照与简单基线，再在固定划分上比较模型。需要先核实适用数据和独立重复；资料缺失不应用摘要数值补齐。
