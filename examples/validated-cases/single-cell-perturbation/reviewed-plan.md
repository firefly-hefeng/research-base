## 研究问题与固定划分

先分别定义三个预测目标：未见扰动 U-pert、未见细胞背景 U-ctx、两者同时未见 U-both。目标是从允许的对照表达、扰动标识和训练材料预测响应，不使用测试扰动细胞作为模型输入。

每个目标固定训练、验证、测试和排除记录的清单，保留基因面板、剂量、时间、细胞类型、donor、批次及数据版本。至少重复多个预先选定划分；模型调参只用训练/验证部分。HVG、PCA、标准化中需拟合的参数、响应参考均值和可学习权重均在训练折内估计。对新细胞背景仅允许使用对照细胞的设置，明确命名为有对照背景信息的外推；与完全无目标背景信息的设置分开。

组合扰动分别报告 Seen0、Seen1、Seen2，指组成单扰动在训练中见过 0、1、2 个，测试组合自身均未见。旧方案已有这些概念，本轮主要补足与论文协议的对应。保留加性基线，并报告非加性残差、组合覆盖和效应大小；不只依赖 Norman19 判断能否学习非加性交互。Calibration 对该数据集的加性饱和讨论不能推出所有组合数据集均无学习空间。

化学扰动另设 scaffold 留出和 cell×scaffold 联合留出。联合测试是两个留出组的交集，只满足一个留出条件的记录进入排除集，不能偷偷回流到训练。审计同药物、同 scaffold、同细胞背景、剂量邻居、MoA 重叠及最近训练化合物的连续相似度。另做训练量、测试量匹配的随机划分对照，避免把全部差异归因于化学邻近性。Leakage-aware 的全队列 top-2000 基因选择属于其自述的转导式限制，本研究采用训练折选基因或外部固定基因面板。

## 可部署基线与评价对照分开

可部署基线至少包括对照均值、训练扰动均值、匹配均值及按任务定义的线性/加性方法。训练扰动均值应明确是“所有细胞等权”还是“先求各扰动均值再扰动等权”，不能把两者当作同一实现；保留 Systema 原定义用于复现，另列 Calibration 的扰动等权版本。

U-ctx 可加入“目标背景对照 + 其他训练背景的同一扰动平均效应”、对照 PC 空间最近邻迁移和简单 ridge。若 U-both 中该扰动在任何训练背景都未见，这个扰动特异参考不可直接计算，必须预先声明全局回退或不适用。整背景留出时，不能使用该背景的测试扰动表达计算所谓训练 ContextMean。

模型组根据输入、输出和支持任务选择，例如 GEARS、scGen、CPA，以及具有可验证适配器的基础模型。对 CPA 保留旧方案中的输入修正检查和未被替换的真实评分数据；不能将 scPerturBench 的历史问题推给所有其他论文实现。Comparison 明确给基础模型使用对照输入和扰动训练目标，应按实际代码与版本核验。

技术 duplicate 和 interpolated duplicate 是**评价期的阳性参照**：它们可访问测试扰动的独立细胞子集，不能进入普通零样本模型的输入、训练或排行榜，不能称作可达到的部署性能保证。细胞拆半主要反映该样本的抽样变异，不等于独立生物重复测得的可靠性上限。复现 Calibration 时，将构建阳性参照的 TD 细胞、构建评价权重/掩码的 GT 细胞及模型训练数据清楚分开；不同数据集需核查适用条件。

## 指标与质量门

1. **先检验评价灵敏度。** 在固定验证协议下比较阴性均值参照与阳性 duplicate 参照，用 DRF 或明确的阳阴性差距检查候选指标能否识别已知信号。阳性参照接近阴性不等于整个数据集不可研究，应先区分指标不灵敏、样本不足、效应弱及实现错误。指标集合和调整规则在测试前固定，不能按某模型获胜再选择指标。
2. **互补报告而非预设单一赢家。** 保留绝对误差、明确参考的 PearsonΔ/R²、扰动特异加权误差和 retrieval/discrimination 指标。标准 MSE 可作为整体表达合理性检查；校准后的指标也不能单独代表全部生物学目标。均值模型与其自身 delta 参考相减成为零向量时，相关系数为不适用，记录 NA 和有效样本数，不随意填 0 或纳入平均。
3. **共享 control 偏倚诊断。** 在相同模型输出上并列比较 shared-control 与重复 independent-control-split 的 PearsonΔ，记录控制细胞数与拆分不确定性。拆分降低共享噪声造成的膨胀，但仍可能向零衰减，不能宣称普遍无偏或自动指定为唯一主指标。使用独立、互不重用的控制组构造 null 预测与参考，依据有限样本的经验零分布/区间判断异常，而非要求数值严格等于零。异常先触发评分与独立性检查，不直接断定存在训练测试泄漏。
4. **DE 与分布定义固定。** Systema Δ20 与 Comparison 的显著 DE top-N overlap 分开实现。后者对显著基因不足 N 的条件不计算，应报告覆盖数及效应大小分层，防止删去弱效应条件后给出偏向性总分。明确 MMD 是逐基因边际距离后汇总，还是多基因联合分布距离；不能把前者等同于协方差恢复。均值型模型不应凭构造的伪细胞数获得虚假的 DE 显著性。
5. **可靠性与残差任务是条件化分析。** 有独立重复测量时，可分析扰动响应及其背景特异残差的可重复性。LOCO 的残差响应、训练折权重和零残差 drug-mean 参考只能作为适合该任务的待复现选项；不把 w>0.1 固定移植到全部遗传或组合任务。缺少相应重复、标准误或非零残差分母时报告不可估计，不编造 ceiling。

不确定性单位跟随真实抽样设计，例如扰动、药物、donor 或生物重复；不要将大量单细胞或共享训练数据的 CV 折当作独立生物重复。保留旧方案的 dropout/overdispersion 稳健性，但其与真实生物变异分开解释。

## 执行顺序与可证伪结论

先选一个遗传扰动数据集和一个适合跨背景或化学划分的数据集，完成清单、输入契约、阴阳性评价对照及简单基线。先确认指标在数据量允许的范围内具有辨别能力，再训练模型；一个数据集一轮小规模试跑只用于测实际内存、时间和输入输出，不作为科学比较。

随后在固定任务和相同可用信息下扩大到多个数据集和划分，报告模型相对合适简单基线的配对差异、区间、效应分层和不适用项。只有覆盖预先定义的条件，才讨论某方法是否表现出可复现增益。不能仅以“两个种子超过基线”宣布新方法成立，也不能因一个指标失败推出所有预测均无效。

不承诺 CPU 数小时、固定一张 GPU 或 U-both 与 Seen0 算力等同；这些均需实际小规模计时后估算。保留代码版本、数据与划分清单和结果表，但不要求逐篇知识卡。

## 本轮能证明什么

新增原文使方案能够发现指标校准、共享参考噪声、严格联合留出、均值权重及材料可复现性方面的具体问题，修改可定位到方法页。旧方案已有的训练折特征选择、组合分组、加性基线、原件读取和 CPA 修正主要得到确认或细化。

目前证明的是文献组件能带来实际可读的新材料并支持方案纠错；原模型仍产生了阅读范围和方法泛化错误，独立复核是本轮质量的一部分。没有证明节省了多少人工时间、提高了预测准确率、覆盖全部前沿，或无需研究者复核即可执行方案。
