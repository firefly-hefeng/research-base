# RAG 资料扩展的实际帮助与边界

这是对旧方案、第二次真实 DeepSeek 回答和独立复核稿的定性比较。修复续读接口后，本次 8 次阅读返回了 5 篇新增主文的指定完整页；Conformal 第 3 页正确续读，没有重复首轮的错页偏移。原始回答未覆盖。

| 设计选择 | 相对旧方案的变化 | 模型实际读取依据 |
| --- | --- | --- |
| 人工/合成 QA 分轨、词面偏差控制 | 新增明确数据构造变量，避免将容易匹配的合成问题当真实用户需求 | German Hybrid Retrieval 4、9；Admissions 12。单机构/生成数据结果不作普遍因果结论 |
| 配额去重 hybrid | 新增区别于原名次/分数融合的可选配置，并要求最终 unique chunks/token 公平 | German 第 4 页。参数只能作为待测试候选，不能把德语结果直接迁移到中文 |
| 按组阈值的 claim 后处理 | 提供新的待验证路线；明确独立校准、组标签、标注正确性和覆盖代价 | Conformal 第 3 页。校准真值的细节来自独立复核补读第 2 页；后处理改变回答，不是被动诊断 |
| 成本和人工复核门槛更具体 | 部分加强；旧方案已有分段P50/P95、人工一致性与评价器检查 | METIS 3、13及judge survey 6。端到端时延定义可借鉴，F1/作者时延效果不能代替本实验忠实性或收益 |
| 四组检索、预算匹配、指标骨架、扰动 | 主要是确认项，不计为新增创新 | 旧方案已包含，新增文献没有证据要求取消这些控制 |

独立复核进一步纠正了：调参与校准集混用；把claim过滤仅称作诊断指标；区间跨0被写作无收益；拒绝借鉴METIS时延定义；任意时延比率被当默认标准。复核补读的German指标公式与survey检索截止明确另列，没有冒充模型亲读。

因此，本轮有“研究设计更具体、能识别若干适用条件”的可核验帮助，也验证了续读接口改善了实际资料消费。尚无RAG基准结果、人工研究者盲评或节时对照，不报告性能提升、效率百分比或完整前沿覆盖。
