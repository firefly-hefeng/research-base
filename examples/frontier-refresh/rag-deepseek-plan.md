# RAG 评价方案：DeepSeek 实读后的独立修订版

DeepSeek 实际通过研究接口读取 FRESCO 物理第 3–4 页、EBG 第 3–4 页、RARE 第 6–7 页，6 次单页调用完整返回 26,665 个字符，读取范围声明准确；原文使用与匹配检索的新鲜度检查均通过。检索范围是 2025-01-01—2026-11-03 的既定 arXiv 查询和声明的 ACL 元数据集合，不代表全领域覆盖。本稿与原始模型输出及先前本地 agent 方案分别保存；独立复核另读 FRESCO 第 5 页核对指标定义，不能归作 DeepSeek 已读。本轮未运行科研实验。

保留旧方案中冻结语料、分块、生成器、top-k 和上下文预算的控制；开发、校准、测试查询分离，相近问题分组；配额混合与 RRF 独立比较；问题级命中、答案正确、claim 支持、完整性、校准及成本继续分别报告。

1. **增加语义充分与时间有效性的联合诊断。** FRESCO 第 3–4 页的困难负例包括过期但相关的证据，以及时间有效却不足以回答的证据，不应简化为一般无关段落。构造带查询时间的版本对，人工核对事实有效期，分别测试显式、隐式时效问题和静态问题，并消融时间戳。按组报告 MRR、nDCG 和命中率。独立补读第 5 页后，明确 Obsolete Ratio 是“排在正例之前的负例中，事实过期者的比例”，不是 top-1 过期比例；分母及无此类错误时的处理应在实现前固定。作者的样本质检结果不能替代本语料的独立核验，改善幅度仍需实验。
2. **把证据可得、使用和联合正确拆开。** EBG 第 3 页的答案、证据及联合正确分别报告，联合项要求两者同时满足，不作加和；输出采用可容纳多项证据的 `lines` 数组。对两事实问题，同时记录“至少取回一个”和“全部必要信息已取齐”，再比较答案与支持完整性。加入固定正确证据上下文作利用诊断；按第 4 页的思路控制证据位置及上下文长度，先验证小规模问题可解性，再按实际模型能力和预算扩展长度。原论文合成试验的短上下文成功率不是我们的基线结果，也不证明现实事实正确或长上下文普遍更好。
3. **让等价证据有效，并分别量部分覆盖和全覆盖。** RARE 第 6–7 页支持将经核验的替代段落纳入 gold，避免只认唯一来源；同一信息重复出现不能重复计数。检索层同时报告 Coverage@K 和 PerfRecall@K，保留生成与成本指标；按跳数、相似性及事实冗余分层，不把跨域关联写成独立因果效应。若采用 LLM 造题过滤，明确原文以“失败样本”为正类：高召回关注识别坏内容，适中的精度可能误删有效内容。人工分别抽查保留的坏样本和被排除的有效样本，不把作者过滤率直接定为实验室验收阈值。

先构造可人工检查的诊断集，冻结标签、分组、指标和计算预算，再统一运行检索与生成，报告不确定性与耗时。标签争议或时间有效期不清时先修评价集；答案分提高而完整支持不改善时，不宣称更忠实；时效与静态任务发生冲突时报告取舍。

仍需补读三篇代码、完整设置与限制，以及 RARE 标注流程和 FRESCO 指标实现约定。既有 conformal 后处理本轮未重读，继续保留标注可靠性和分布条件核查。上述三项是新增原文支持的待检验研究改进，没有产生新实验性能、通用排名或无人复核科学正确性的结论。
